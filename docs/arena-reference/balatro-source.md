# 小丑牌 · Jev 单人挑战

本游戏是 Token Arena 自行实现的简化规则 `arena-balatro-v2`，不是完整 Balatro。仅支持免费 Jev 挑战赛；不支持邀请赛、双人匹配或正式赛。Jev 是关卡主持，不出牌、不调用模型。只有玩家行动。

先按操作引导读取当前已登录账号的大厅或指定当局。若用户已创建挑战，直接接管该 match_id，不要再次 join。新建一场仅在用户授权后调用 `token_eco_arena_join`：`game: "balatro"`、`opponent: "jev"`、`stake_usd: 0`、一个新 UUID v4 `request_id`。不要传扑克的 max_hands 或 practice_chips。

`next_action: ready` 时，以当前 version 调用 `token_eco_arena_ready`；准备成功后立即发牌。始终保存 response.match。游戏状态在 `match.balatro`；没有五子棋 board、chess 或 poker 字段。

## 目标与资源

- 默认 4 个 Ante，每个按小盲注、大盲注、Boss 盲注顺序进行，共 12 关。压缩原版白色难度 Ante 1/3/5/8 的分数曲线，覆盖开局到终局，而非只到中段。Boss 目前只有分数门槛，没有特殊限制。

| Ante | 小盲注 | 大盲注 | Boss 盲注 |
| ---- | ------ | ------ | --------- |
| 1    | 300    | 450    | 600       |
| 2    | 2000   | 3000   | 4000      |
| 3    | 11000  | 16500  | 22000     |
| 4    | 50000  | 75000  | 100000    |

- 每关重新洗一副 52 张标准牌，手牌上限 8 张；4 次出牌、3 次弃牌。
- 每次出牌或弃牌选 1–5 张不同的现有手牌，操作后从剩余牌堆补足 8 张。
- 弃牌不消耗出牌次数；已出或已弃的牌本关不再抽到。
- 本关累计得分达标即过关。前 11 关各有三选一未拥有的小丑奖励，可跳过；同一动作还可以选择一种牌型升 3 级（星球奖励）。小丑与牌型等级保留，本关分数和次数重置。
- 开局没有小丑，最多装备 5 张，满槽需指定替换的已有小丑，也可保留当前组合并跳过小丑奖励。
- 12 关全部通过获胜。出牌次数用尽仍未达标，挑战失败。每次行动（含奖励选择）10 分钟，超时或认输均失败。准备超时或准备前取消不计胜负。
- 游戏得分、计分筹码和倍率与账户余额无关；没有积分预留、充值或结算。

## 动作协议

只在 `next_action: balatro_action` 时调用 `token_eco_arena_balatro_action`。传 `match_id`、所分析快照的 `expected_version` 和新 UUID v4 `request_id`，以及以下一种动作：

| balatro_action | 参数                                                                                                                  | 可用阶段                     |
| -------------- | --------------------------------------------------------------------------------------------------------------------- | ---------------------------- |
| play           | cards: 1–5 个不同手牌 ID                                                                                              | playing                      |
| discard        | cards: 1–5 个不同手牌 ID                                                                                              | playing 且 discards_left > 0 |
| choose_joker   | joker_id: reward_choices 中的一项 ID；满 5 槽时另传 replace_joker_id: jokers 中一项 ID；可传 upgrade_hand；不传 cards | reward                       |
| skip_reward    | 保留已有小丑；可传 upgrade_hand；不传 cards、joker_id 或 replace_joker_id                                             | reward（仅 v2）              |

例如 `cards: ["AS", "AH"]` 表示黑桃 A 与红桃 A。牌点 2–9、T（10）、J、Q、K、A；花色 S 黑桃、H 红桃、D 方块、C 梅花。使用返回的牌 ID，不用数组下标或显示文字。

每次读取最新的 `balatro.legal_actions`、`hand`、`jokers`、`reward_choices`。不确定是否提交成功时重用原 UUID 和完全相同参数；版本冲突时保存返回快照，重新决策后用新 UUID。服务端不接受客户端分数、牌堆或胜者。

出牌后通常仍轮到你，不要等待 Jev。进入 reward 后选择小丑（满槽指定 replace_joker_id）或 skip_reward 即开始下一关。奖励动作均可传 upgrade_hand 指定一种牌型升 3 级；省略时默认升级 last_score.hand_type。这不是所有牌型一起升级。`done` 时报告通关结果、cleared 和 total_score，停止操作，不要自动再开一场。

## 计分

分数为 `floor(筹码 × 倍率)`。筹码 = 对应等级的牌型基础筹码 + 组成牌型的计分牌点数 + 小丑筹码。倍率 = （对应等级的牌型基础倍率 + 小丑加法倍率）× 小丑乘法因子。所有加法先于所有乘法；无需排列小丑。

| 牌型   | 基础筹码 | 基础倍率 | 计分牌                         |
| ------ | -------- | -------- | ------------------------------ |
| 高牌   | 5        | 1        | 最高一张                       |
| 对子   | 10       | 2        | 两张对子                       |
| 两对   | 20       | 2        | 两组对子                       |
| 三条   | 30       | 3        | 三张同点数                     |
| 顺子   | 30       | 4        | 五张；A2345 合法，QKA23 不合法 |
| 同花   | 35       | 4        | 五张同花色                     |
| 葫芦   | 40       | 4        | 五张                           |
| 四条   | 60       | 7        | 四张同点数，边牌不计           |
| 同花顺 | 100      | 8        | 五张；皇家同花顺按此计         |

A 计 11 筹码，J/Q/K 计 10，其余计牌面值。对子、三条等不计边牌；红牌、皇家等小丑也只作用于计分牌。

所有牌型初始 Lv.1。每次奖励可选择一种牌型升 3 级；使用返回的 `hand_levels`，未列出的牌型为 Lv.1。升级先改变基础筹码/倍率，再加小丑效果。每级成长为：

| 牌型   | 每级筹码增量 | 每级倍率增量 |
| ------ | ------------ | ------------ |
| 高牌   | 10           | 1            |
| 对子   | 15           | 1            |
| 两对   | 20           | 1            |
| 三条   | 20           | 2            |
| 顺子   | 30           | 3            |
| 同花   | 15           | 2            |
| 葫芦   | 25           | 2            |
| 四条   | 30           | 3            |
| 同花顺 | 40           | 4            |

新局不再自带「开场小丑」，可作为 +4 倍率奖励选取。奖励池有 +50 筹码、含对子 +8 倍率、同花 +10、顺子 +12、每张红牌 +3、每张 J/Q/K +30 筹码、倍率 ×1.5、最后一次出牌倍率 ×2。以返回的 description 为准。奖励 3 项不同且不含已拥有小丑；可选一项或跳过小丑（仍领取指定牌型升级），没有商店、牌面强化或消耗品。

`last_score` 提供牌型、played_cards、scoring_cards、chips、mult、score 和 effects；`history` 保存至多 48 次出牌的计分明细。牌堆顺序永不公开。

难度设计参考：[官方玩法 FAQ](https://www.playbalatro.com/faq/)（每个 Ante 三道盲注，原版通常在 Ante 8 结束）、[盲注分数](https://balatrogame.fandom.com/wiki/Blinds_and_Antes)、[星球卡成长](https://balatrogame.fandom.com/wiki/Planet_Cards)。本挑战压缩为 4 个 Ante，并以过关定向升 3 级替代原版商店中的星球购买；不是完整原版玩法。
